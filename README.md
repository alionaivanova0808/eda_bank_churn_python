# Исследовательский анализ данных (EDA): Отток клиентов банка

**Анализ оттока клиентов банка** - выявление факторов, влияющих на уход клиентов, и формулирование рекомендаций для их удержания.

## Источник данных
Датасет **Churn_Modelling.csv** с платформы [Kaggle](https://www.kaggle.com/datasets/shubhammeshram579/bank-customer-churn-prediction) (или GitHub: [AI-Data-Space/BankingRetentionOptimizer](https://github.com/AI-Data-Space/BankingRetentionOptimizer)).  
Содержит 10 000 записей клиентов банка, 14 признаков (география, возраст, баланс, количество продуктов, активность и др.).

## Цель проекта
Провести разведочный анализ данных, чтобы:
- Определить **профиль клиента, который чаще всего уходит**.
- Найти **ключевые факторы**, влияющие на отток.
- Сформулировать **рекомендации для отдела маркетинга** по удержанию клиентов.

## Стек технологий и библиотеки
- **Python 3** – язык программирования
- **Pandas** – загрузка, очистка и агрегация данных
- **Matplotlib & Seaborn** – визуализация (гистограммы, boxplot, countplot, тепловая карта корреляции)
- **Jupyter Notebook** – интерактивная среда разработки

## Содержимое репозитория
- `eda_bank_churn.ipynb` – Jupyter Notebook с полным исследованием (код, графики, выводы)
- `README.md` – описание проекта
- (опционально) `requirements.txt` – список зависимостей Python

## Основные выводы (инсайты)
1. **Общий уровень оттока** – 20.4%. Это целевой показатель, который нужно снижать.
2. **География:** Клиенты из **Германии** уходят значительно чаще (32%), чем из Франции (16%) и Испании (17%).
3. **Возраст:** Клиенты в возрасте **50–59 лет** демонстрируют пик оттока (около 36%). Самые лояльные – молодые люди до 30 лет.
4. **Количество продуктов:** Клиенты, использующие **1 продукт** банка, уходят в 4 раза чаще, чем те, у кого 2 продукта. При 3 и 4 продуктах отток сильно растёт (возможно, из-за сложности или навязывания услуг).
5. **Активность:** Неактивные клиенты (`IsActiveMember = 0`) уходят почти в **2 раза чаще** активных.
6. **Баланс:** У ушедших клиентов средний баланс выше, чем у оставшихся. Это может говорить о недовольстве качеством обслуживания «дорогих» клиентов.

## Рекомендации для бизнеса
- **Программа лояльности** для возрастной группы 50–59 лет (повышенный кэшбэк, персональные предложения).
- **Кросс-продажи** – клиентам с 1 продуктом активно предлагать второй (например, кредитную карту к дебетовой).
- **Реактивация неактивных клиентов** – напоминания, бонусы за возобновление операций.
- **Работа с регионом Германия** – аудит сервиса, возможно, дополнительные колл-центры или специальные тарифы.
- **Для клиентов с высоким балансом** – выделить премиального менеджера или улучшить условия обслуживания.

## Как воспроизвести проект
1. Скачать репозиторий:  
   `git clone https://github.com/твой-логин/eda-bank-churn-python.git`
2. Перейти в папку проекта, установить зависимости:  
   `pip install -r requirements.txt`
3. Запустить Jupyter Notebook:  
   `jupyter notebook eda_bank_churn.ipynb`
4. Последовательно выполнить ячейки ноутбука.
